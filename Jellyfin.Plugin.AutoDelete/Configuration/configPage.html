Auto Delete Watched Episodes

Episodes are deleted once every watched episode in the selected libraries has been watched longer ago than the delay below. The most recent watch by any user restarts the countdown.

The cleanup runs as a scheduled task (Dashboard → Scheduled Tasks → Delete watched episodes) and can be triggered manually with the button below.

When disabled, the scheduled task does nothing at all.
While enabled, the task only writes what it would delete to the Jellyfin log. Leave this on until you are happy with the results, then turn it off to start deleting.
How long an episode is kept after it was last watched. For example 24 Hours.

Libraries to watch

Only episodes from the selected libraries are considered, so pick your TV libraries. If no library is selected, nothing is deleted.

Cleanup of empty folders

A series is only removed when none of its episodes are left in the library.
Leftover artwork, subtitles and metadata files are removed with it. The folder is kept if it still contains video files, or if it is a library folder itself.
Useful when only part of a series was deleted.
